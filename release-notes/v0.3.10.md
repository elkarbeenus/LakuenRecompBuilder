LaküenRecomp v0.3.10 is one build for a PC, the Steam Deck and the Legion Go S. It fixes two ways old bytes reached the
picture: uniform updates landing out of order, and textures uploaded from an earlier frame's copy of their memory.

This release contains no game data, keys or executables: the AppImage is the builder, which builds the game on your PC from
your own copy. All of the recompilation work is NotRexed's and the Hookshot contributors'.

## Fixed
- **Uniform updates land in the game's order:** the game updates one uniform block many times in a frame (4, 16 and 64
  bytes), and each update was one GPU write with no barrier between them; two writes of the same bytes may land in either
  order, and the older values could be the ones left for the next frames. The validation layer counted about 70 such pairs a
  frame on RADV, among other places in the Zora's domain. A frame's updates are now sorted, and those that overlap are
  combined in the game's order into one write: no write overlaps another, and no barrier is needed (one cost ~2 % fps).
  `RX_VK_UB_ORDERED=0`: as before. From HeyListen (Mooseca).
- **No more one-frame flashes of white, magenta or wrong colours at area loads:** the game streams an area's lightmaps and
  materials into memory another texture used, and fills or rewrites it after submitting the draws that use it. The copies
  of those pages kept for the texture uploads were often from earlier frames, so an upload read the old texture: lighting
  blown out to white and magenta, a bloom, walls in lighter colours for a frame. An upload now takes a copy only when the
  current frame's capture took it, and reads the game's memory otherwise. HeyListen: 0 of 20 arrivals with a flash, 3 of 20
  without. `RX_VK_FIRST_UPLOAD_OWN=0` / `RX_VK_REUPLOAD_OWN=0`: as before. From HeyListen (Mooseca, issue 66).

## Known issues
- Some places look too bright in a white haze (a fairy's fountain, the Zora's domain); the cause is open. If this release
  changes it, please say so.
- Busy areas (the open field) drop below 30 fps now and then on handhelds.
