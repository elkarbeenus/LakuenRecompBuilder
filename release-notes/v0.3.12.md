LaküenRecomp v0.3.12 is one build for a PC, the Steam Deck and the Legion Go S. It steadies the game's exposure meter:
fewer white flashes and less flicker at night.

This release contains no game data, keys or executables: the AppImage is the builder, which builds the game on your PC from
your own copy. All of the recompilation work is NotRexed's and the Hookshot contributors'.

## Fixed
- **A steadier exposure:** the game measures the picture's light with two compute programs that add a frame's sums into a
  small block, which the game reads and sets back to zero. With the game ahead of the GPU, its zeros could reach the GPU
  late, or an older write-back could bring the old sums back over them: the next frame's sums were added on top (twice the
  light), or a read found only zeros. The exposure stepped: white flashes and a flicker at night. The sums are now cleared on
  the GPU right before each of the two programs, and a read that finds only zeros is given the last result again.
  `RX_VK_METER_ZERO=0` / `RX_VK_METER_HOLD=0`: as before. From upstream Hookshot (pixl27), via HeyListen.

## Kept
- The PC profile, Fog boxes (Off), Fog density and Brightness (100 %), the in-game diagnosis, the master log after every run,
  Update inside the builder, the fixes of v0.3.8 to v0.3.11. The prepared shaders stay: nothing here changes the shader
  translation.

## Known issues
- Some places look too bright in a white haze (a fairy's fountain, the Zora's domain); the cause is open. If this release
  changes it, please say so.
- Busy areas (the open field) drop below 30 fps now and then on handhelds.
